# Basics Notions (ITC1)
## Divisor
$a, b \in \mathbb{Z}$ 

$a$ is a divisor of $b$ if there exists some $c$ such that, $b = ac$ 
	This is denoted as $a |b$  _(a divides b)_ 

$a$ is called a _PROPER_ divisor if,
	$a \in (1,|b|)$ 
___
## Prime
$p \in \mathbb{Z}$ is called a _prime_ if
	$|p| > 1$ 
	$p = ab$ holds iff 
		$a = \pm1$ 
		or $b = \pm1$ 
			_this is the same as saying:_ $p$ has no proper divisors

If $|p| >1$ but it is not a prime, $p$ is then called a _composite_ number.
