## Sample Space
let $\ohm$ be an arbitrary set,
	Sample space: $\ohm$
	Outcome: an element $\omega \in \ohm$
	Events: Selected subsets $A \subseteq \ohm$ 
	Probability: A number $P(A) \in [0,1]$ 
		$P(A)= \frac{|A|}{|\ohm|}$

## Properties
1. $\bar A = \ohm \backslash A$ 
2. $A \backslash B = A \cap \bar B$ 
3. $P(A \cup B) = P(A) + P(B)$ when $A$ and $B$ are disjoint i.e,  $A \cap B = \phi$ 
4. Impossible event: $\phi$ : Empty Set: $P(A)=0$
5. Certain event: $\ohm$ :  : $P(A)=1$

## DeMorgan's Laws
1. $\overline{A \cup B} = \bar A \cap \bar B$
2. $\overline{A \cap B} = \bar A \cup \bar B$

## Event Algebra ($\digamma$)
- The collection of all events is a set called _event algebra_
- Event algebra is NOT a subset of $\ohm$
- All the subsets of $\ohm$ is called the _power set $\wp$_ 
$$
\begin{align*}
 \ohm &= \lbrace 1,2,3 \rbrace \\
 \wp (\ohm) &= \lbrace \phi, \lbrace 1 \rbrace, \lbrace 2 \rbrace, \lbrace 3 \rbrace, \lbrace1,2 \rbrace, \lbrace 2,3 \rbrace, \lbrace 3,1 \rbrace, \lbrace 1,2,3 \rbrace \rbrace \\
 &The\ power\ set\ is\ a\ set\ made\ up\ of\ sets
\end{align*}
$$
- $\digamma \subseteq \wp (\ohm)$


Let $\ohm$ be an arbitrary set
$\digamma$ be a collection of subsets of $\ohm$
	We say that $\digamma$ is $\delta$ - Algebra _($\delta$ - algebra = Event algebra)_
1. $\ohm \in \digamma$
2. If $A \in \digamma$, then $\bar A \in \digamma$ 
3. If $A_1, A_2... \in \digamma$ then, $\bigcup_{i=1}^{\infty} A \in \digamma$
